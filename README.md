# Канал Бурмалды — эфир

Это локальный сайт для запланированных видеоэфиров: автор выбирает ролик и время старта, а зрители открывают отдельную страницу с заставкой и обратным отсчётом. В момент старта на странице появляется загруженное видео.

## Запуск

1. Установите Python 3.11 или новее с сайта [python.org](https://www.python.org/downloads/windows/) и на первом экране установки отметьте **Add Python to PATH**. Это требуется один раз.
2. Дважды нажмите `start.bat`.
3. Для автора откройте `http://127.0.0.1:5000/creator`.
4. Для зрителей откройте `http://127.0.0.1:5000/watch`.

На телефоне в той же Wi‑Fi сети замените `127.0.0.1` на IP‑адрес компьютера. Например: `http://192.168.1.25:5000/watch`.

## Что умеет

- Принимает MP4, WebM, MOV и M4V до 900 МБ.
- Хранит одну ближайшую трансляцию: новая публикация заменяет прежнюю.
- Показывает фирменный логотип до эфира и выводит видео в назначенное время.
- Обновляет состояние страницы зрителя автоматически, даже если она уже открыта.

При локальном запуске `start.bat` попросит придумать пароль для страницы автора. Открывайте `/creator`, вводите этот пароль и никому его не передавайте.

## Публичная ссылка для зрителей

Проект подготовлен для Render: файл `render.yaml` задаёт запуск сайта и отдельное постоянное место для базы и загруженных видео. Создайте в Render новый веб‑сервис из папки проекта, после запуска сервис даст ссылку наподобие `https://burmaldy-live.onrender.com/watch`. Эту ссылку можно отправлять зрителям.

В Render добавьте две переменные в разделе **Environment**: `CREATOR_PASSWORD` (ваш пароль) и `SECRET_KEY` (создайте через кнопку Generate). Видео хранятся на постоянном диске размером 1 ГБ, поэтому для этого варианта нужен платный веб‑сервис Render. Также учитывайте, что большие видео занимают место; для постоянного канала удобнее хранить ролики в специальном видеохранилище.
